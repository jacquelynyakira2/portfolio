# Micrographics

![Micrographics template gallery](img/projects/micrographics-hero.png)

## Overview

**Micrographics** is a browser-based micrographics editor I built to make small, layered graphics — labels, marks, posters, technical layouts — without opening a heavy design tool. Pick a template, edit layers on a canvas, and export.

🔗 **[Open Micrographics](https://micrographics.jacquelynyakira.com/)**

## What it is

- A **template-first** editor with **96 templates** (many free; Pro unlocks the full set)
- Layered canvases you can search, open, rename, and resize
- Tools for **text**, **shapes**, **components**, and **graphics** — plus SVG/PNG export
- Dark and light modes for both the gallery and the editor

![Micrographics editor — Ideas Get Loud](img/projects/micrographics-editor.png)

## Why I built this

I wanted a place to play with a very specific visual language: tight typography, barcodes, care-label energy, industrial marks — the kind of graphics that feel like stickers and specs more than “marketing posters.” Building the editor itself was part of the experiment: ship a real product on my own domain, with a template library and a working export path.

## Try it

1. Browse or search templates at [micrographics.jacquelynyakira.com](https://micrographics.jacquelynyakira.com/)
2. Open one in the editor
3. Edit layers, tweak the canvas, export SVG or PNG
